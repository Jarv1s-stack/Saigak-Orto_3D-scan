# Saigak-Orto — локальный краниометрический прототип

Локальный прототип загрузки STL-модели, 3D-просмотра, оценки качества сетки, настройки сечения и геометрических измерений. Скан не отправляется во внешние сервисы. Результат предназначен только для проверки врачом; это не диагностический продукт и не основа для назначения лечения или шлемотерапии.

## Запуск

Требуются Node.js 20 или новее.

```powershell
npm install
npm start
```

Откройте `http://localhost:3000`. Модель и отчёты обрабатываются на локальном сервере; имя, дата рождения, клиника и другие персональные данные не собираются. STL-файлы сохраняются локально в `data/clinical-scans/`. Скан-состояние хранится в памяти и очищается после перезапуска, но STL-файлы остаются на диске до ручного удаления.

## Реализованный прототип

- Загрузка ASCII и binary STL с проверкой размеров, конечности координат, вырожденных граней, граничных и несогласованных рёбер.
- Интерактивный просмотр 3D-модели (вращение/масштаб), плоскости сечения, осей, диагоналей и пользовательских отметок.
- Устойчивое пересечение STL треугольников плоскостью, в том числе при совпадении плоскости с вершинами/рёбрами; масштабное объединение точек, удаление дубликатов сегментов и диагностика открытых/ветвящихся компонентов. Для измерений выбирается крупнейший однозначный замкнутый контур; положение плоскости не смещается автоматически.
- Автоматическая ориентация главной оси по равномерно распределённым по длине контура точкам, чтобы снизить влияние неодинаковой плотности триангуляции; ручная коррекция наклона X/Y и поворота Z, единиц, сечения и угла диагоналей; отметка четырёх концов диагоналей с пересчётом.
- Геометрические CI = 100 × W / L, CVA = |D1 − D2|, CVAI = 100 × CVA / max(D1, D2), длина L/ширина W, D1/D2 и периметр замкнутого сечения. Пороги асимметрии указаны в интерфейсе и экспортах. Категорию CVAI определяет неокруглённое значение. Степень по CI не назначается без утверждённого профиля.
- Исследовательская радиальная карта асимметрии 2D-сечения и раздельные фронтальная/затылочная оценки с явным выбором направления передней стороны; эти показатели не являются клиническими шкалами.
- Экспорт PDF, CSV и JSON, анонимный код скана, флаги качества, версии методики/модели и врачебная отметка.
- ML v2: 24 радиальных признака с шагом 15° на основе пересечений лучей с контуром, нормализованных относительно площадного центроида; v1-веса на 12 признаках остаются совместимыми.
- Воспроизводимый локальный скрипт обучения ridge-регрессора и сравнения с mean-baseline, а также отдельный скрипт псевдоразметки для технического демо: [ml/README.md](./ml/README.md).

Методика геометрии обновлена до `cranio-geometry-0.2.0`. Подробности алгоритмов и формата v2 ML-признаков описаны в [ml/README.md](./ml/README.md).

## Ограничения

В папке исходников нет экспертно размеченных клинических сканов. Поэтому при первом запуске **обученных ML-весов нет**: приложение использует прозрачный геометрический алгоритм, а не выдаёт экспертные ориентиры за ML-прогноз. После получения разрешённого анонимизированного набора заполните CSV по схеме в [ml/README.md](./ml/README.md) и обучите модель локально. Разделение осуществляется по уникальному коду скана; протокол предполагает не более одного скана на ребёнка.

Текущая автоматическая ориентация по главной оси сечения не определяет анатомические направления «лоб/затылок». Длины D1/D2 являются геометрическими проекциями контура в направлениях ±30°, а не клинически утверждённой разметкой анатомических ориентиров. Замкнутость сетки не подтверждает полноту скана. Возраст 0–18 месяцев является поддерживаемым диапазоном метаданных, но клинических возрастных норм в прототипе нет.

Требование ошибки ≤1 п.п./мм и отчёта менее чем за 120 секунд нельзя подтвердить без закрытой экспертной выборки и заранее зафиксированного протокола валидации. Не используйте синтетические данные или тестовые сканы для заявлений о клинической точности.
